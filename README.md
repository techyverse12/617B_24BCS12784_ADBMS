# Advanced Database Management Systems

My lab work for Advanced DBMS at Chandigarh University (CSE, section 617-B), written in PostgreSQL. Each experiment folder has the SQL I wrote and screenshots of the query output.

| # | Topic | What's inside |
|---|---|---|
| 1 | [Inserting and querying records](./Experiment-1/) | A hospital database (doctors, patients, appointments): inserts and first-record queries |
| 2 | [Set operators](./Experiment-2/) | `UNION`, `UNION ALL` and `EXCEPT` for combining and comparing tables |
| 3 | [Aggregation and subqueries](./Experiment%20-3/) | `GROUP BY`, `HAVING`, `DISTINCT`, conditional counting with `CASE`, subqueries |
| 4 | [Joins](./Experiment-4/) | Inner, left and full outer joins, solved as CodeChef SQL problems |
| 5 | [SQL problem solving](./Experiment-5/) | Revenue share calculations and LeetCode SQL problems |
| 6 | [Views](./Experiment-6/) | Views and materialized views, `WITH DATA` vs `WITH NO DATA`, refreshing |

**Stack:** PostgreSQL
